# Hotel PMS Phase 1
Django 5 + DRF based API-first PMS.
## Run
cp .env.example .env
docker compose up --build
## Features
- Modular apps and service layer
- JWT auth
- Reservation overlap validation
- Check-in/out room state automation
- Folio/payments/cash shift models
- OTA + Door lock adapter scaffolds
- Audit logs and reporting endpoint
