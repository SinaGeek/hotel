Storage notes
• File encrypted at rest (SQLCipher); all writes go through client/desktop/src/local_store.rs.
• Migrations run sequentially in init_connection guarded by PRAGMA user_version: 0001 init · 0002 daily rates · 0003 local users · 0004 workflows (desktop_kv, shift_transfers) · 0005 hotels/restaurants/groups/links · 0006 hotel_id scoping on core tables.
• Multi-role users: local_users.role holds a comma-separated role list.
• Hotel code/ID change moves all scoped rows in one transaction (save_local_hotel).
• price_rules.hotel_id (*) and room pricing columns are applied via migration 0007.
